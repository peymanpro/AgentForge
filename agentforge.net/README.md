# AgentForge for .NET

**Status: Planned — not yet implemented.**

This directory is reserved for the idiomatic .NET / C# implementation of AgentForge.

The .NET implementation is expected to have its own solution, source projects, tests, examples, documentation, build pipeline, and NuGet release process.

The initial design will be guided by the [shared specification](../AGENTFORGE_SPEC.md), while remaining idiomatic to .NET. It will not define the architecture for other language implementations.

No stable API or package is available yet.

See the [architecture overview](../docs/architecture.md) and [language implementation guide](../docs/language-implementations.md).
