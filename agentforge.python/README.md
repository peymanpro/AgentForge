# AgentForge for Python

**Status: Planned — not yet implemented.**

This directory is reserved for the idiomatic Python implementation of AgentForge.

The implementation is expected to have its own Python packaging configuration, source code, tests, examples, documentation, and independent PyPI publishing process. Its GitHub Actions workflows are defined at the repository root in `.github/workflows/` and scoped to `agentforge.python/**` plus relevant shared specifications.

The implementation will follow the [shared specification](../AGENTFORGE_SPEC.md) while using Python-native design and conventions.

No stable API or package is available yet.

See the [architecture overview](../docs/architecture.md) and [language implementation guide](../docs/language-implementations.md).
