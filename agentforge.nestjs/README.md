# AgentForge for TypeScript and NestJS

**Status: Planned — not yet implemented.**

This directory is reserved for the idiomatic TypeScript / Node.js implementation, with NestJS integration where it provides value.

The implementation is expected to have its own package workspace, source code, tests, examples, documentation, and independent npm publishing process. Its GitHub Actions workflows are defined at the repository root in `.github/workflows/` and scoped to `agentforge.nestjs/**` plus relevant shared specifications.

The implementation will follow the [shared specification](../AGENTFORGE_SPEC.md) without inheriting .NET-specific abstractions or forcing NestJS conventions on non-NestJS users.

No stable API or package is available yet.

See the [architecture overview](../docs/architecture.md) and [language implementation guide](../docs/language-implementations.md).
